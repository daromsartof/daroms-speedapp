# Skills et agents

| Commande | Rôle |
|---|---|
| `/daroms-day <idée>` | journée complète avec validation entre les étapes |
| `/daroms-idea` | cahier `app.spec.md` |
| `/daroms-new` | création de l'app |
| `/daroms-brand` | marque, icône, splash |
| `/daroms-design` | flux et wireframes texte |
| `/daroms-data` | tables RLS, API |
| `/daroms-screen <nom>` | un écran |
| `/daroms-module <slug>` | un module |
| `/daroms-fix` | auto-réparation (3 essais) |
| `/daroms-check` | vérification complète |
| `/daroms-polish` | finition UX (agent daroms-designer) |
| `/daroms-store` | fiche store (agent daroms-store) |
| `/daroms-build`, `/daroms-submit`, `/daroms-update` | EAS |
| `/daroms-commit`, `/daroms-learn`, `/daroms-skill-new`, `/daroms-release-core` | outillage |
| `daroms-design-system` | traduction des conseils design vers @daroms/ui |

Agents : `daroms-designer` (revue visuelle), `daroms-reviewer` (règles, RLS, bugs), `daroms-store` (ASO).
Skills tiers figés (chargement `name-only`) : voir `_ai/skills/vendor/README.md`.
