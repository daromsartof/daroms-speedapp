# Module onboarding

Pages d'accueil au premier lancement, affichées une seule fois par `version`.

- Activer : `bun daroms module add onboarding` (route `app/onboarding.tsx`).
- Textes : ajouter les clés `onboarding.page1Title`... dans `locales/*.json` de l'app (namespace app).
- Config : `pages` (icône Lucide + clés), `version` (incrémenter pour réafficher).
